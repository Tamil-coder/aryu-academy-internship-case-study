# ARYU Academy — Learning Management Portal

## Project Overview

ARYU Academy is a full-stack Learning Management System (LMS) designed to manage educational activities, student information, course content, tutor operations, batch schedules, attendance, and payment workflows through a centralized platform.

During my internship as a Full Stack Developer at Aryu Enterprises Pvt. Ltd., I contributed to developing and integrating multiple application modules using Django, Django REST Framework, React.js, and PostgreSQL.

My responsibilities included working on backend APIs, frontend interfaces, role-based access control, asynchronous tasks, payment integration, and document generation.

**Project Type:** Internship Project  
**Role:** Full Stack Developer Intern

## Challenges Faced and Solutions

### 1. Role-Based Authentication and Authorization

**Challenge:** Managing access to different modules according to user type required coordination between authentication, permissions, and profile functionality.

**Solution:** Worked on role-based authorization and permission handling to control access to application features based on user type.

### 2. Frontend and Backend Integration

**Challenge:** Integrating React.js components with Django REST APIs required consistent handling of requests, responses, and application data.

**Solution:** Used Postman to test API endpoints, inspect responses, and troubleshoot frontend-backend integration issues.

### 3. Managing Related Learning Data

**Challenge:** Courses, syllabuses, batches, recordings, schedules, and attendance involved related data that needed to be managed consistently.

**Solution:** Worked with Django ORM, PostgreSQL, and REST APIs to manage database operations and integrate the related modules.

### 4. Background Task Processing and Email Delivery

**Challenge:** Automated email workflows and background operations required reliable task execution without unnecessarily blocking application requests.

**Solution:** Worked with Celery to process asynchronous tasks and support background operations such as email generation and delivery.

### 5. Payment Workflow Integration

**Challenge:** Integrating payment-related functionality required coordination between frontend interactions and backend processing.

**Solution:** Worked on Razorpay integration and connected payment-related workflows with the application's backend.

### 6. Webinar and Bootcamp Management

**Challenge:** Managing two types of learning events within the same application required appropriate handling of their respective data and workflows.

**Solution:** Implemented functionality to distinguish webinar and bootcamp types and integrated the relevant operations with frontend components.

### 7. Generating and Downloading Student Reports

**Challenge:** Providing downloadable student lists required transforming application data into a useful document format.

**Solution:** Implemented PDF generation and download functionality for student lists associated with webinars and bootcamps.

### 8. Tutor Dashboard Data Management

**Challenge:** Displaying relevant batch details for tutors required retrieving and presenting information associated with their assigned batches.

**Solution:** Worked on tutor dashboard functionality and integrated the relevant backend data with frontend components.
